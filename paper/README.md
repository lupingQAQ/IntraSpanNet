# GDNet technical report

- `gdnet.md`: Markdown source.
- `gdnet.pdf`: rendered A4 PDF, 9 pages.
- `style.css`: print stylesheet.
- `assets/`: architecture and benchmark figures.

The PDF is generated by converting the Markdown with `marked` and printing the resulting HTML with headless Chrome. The paper uses the same numbers as `docs/RESULTS.md` and `docs/BENCHMARK_AUDIT.md`.

The report is a preprint. It has not been peer reviewed.
