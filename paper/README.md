# GDNet technical report

- `GDNet.md`: Markdown source, IEEE two-column layout.
- `GDNet.pdf`: rendered A4 PDF, 5 pages.
- `style.css`: print stylesheet (two-column, IEEE table rules).
- `assets/`: architecture and benchmark figures.

The PDF is produced by converting the Markdown with `marked` and printing the resulting HTML with headless Chrome at A4 in two columns. Sections follow the IEEE numbering used by MambaNetBurst (Roman numerals for sections, lettered subsections), with captions above tables and below figures.

The report uses the same numbers as `docs/RESULTS.md` and `docs/BENCHMARK_AUDIT.md`.

The report is a preprint. It has not been peer reviewed.
