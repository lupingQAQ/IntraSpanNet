# IntraSpanNet technical report

- `IntraSpanNet.md` / `IntraSpanNet.pdf`: English version, IEEE two-column, 5 pages.
- `IntraSpanNet-zh.md` / `IntraSpanNet-zh.pdf`: Chinese version, same structure and numbers, 6 pages.
- `style.css`: print stylesheet for the English build.
- `style-zh.css`: print stylesheet for the Chinese build (CJK fonts, wider leading).
- `assets/`: architecture and benchmark figures.

Both PDFs are produced by converting the Markdown with `marked` and printing the resulting HTML with headless Chrome at A4 in two columns. Sections follow the IEEE numbering used by MambaNetBurst: Roman numerals for sections, lettered subsections, captions above tables, captions below figures, and a run-in numbered reference block.

The reports use the same numbers as `docs/RESULTS.md` and `docs/BENCHMARK_AUDIT.md`. They are preprints and have not been peer reviewed.
